# 영허검가 (靈墟劍歌)

Three.js로 만든 **뱀서라이크(Vampire Survivors-like)** 게임. 미소녀 + 선협(仙俠) 테마.

마기에 삼켜진 비경(秘境) — 허공에 뜬 옥산 고원에서, 검을 든 소녀 셋 중 하나를 골라
15분을 버팁니다. 공격은 전부 자동입니다. 당신이 하는 일은 **움직이는 것**과
**경지를 돌파할 때 무엇을 얻을지 고르는 것** 뿐입니다.

## 실행

```bash
npm install
```

```bash
npm run dev
```

브라우저가 열리면 캐릭터를 고르고 바로 시작합니다. WebGL2를 지원하는 최신 브라우저가
필요합니다(Chrome, Edge, Firefox).

빌드와 미리보기:

```bash
npm run build
```

```bash
npm run preview
```

## 법보(法寶)와 공법(功法)

**법보 8종** — 비검 · 화염부 · 뇌령주 · 빙백장 · 팔괘진 · 금강저 · 영접부 · 천뢰인.
각 5레벨까지 오릅니다.

**진화 4종** — 법보가 5레벨이고 짝이 되는 공법도 5레벨이면, 돌파 보상에 진화가 뜹니다.

| 법보 | 짝 공법 | 진화 |
|---|---|---|
| 비검 | 검결 | **만검귀종** 萬劍歸宗 — 하늘에서 검비가 쏟아짐 |
| 화염부 | 금단 | **분천화해** 焚天火海 — 터진 자리에 불바다가 남음 |
| 뇌령주 | 영근 | **자소신뢰** 紫霄神雷 — 뇌전이 적에게 연쇄 |
| 빙백장 | 호신강기 | **한천빙봉** 寒天氷封 — 빙결, 죽으면 냉기 폭발 연쇄 |

**공법 6종** — 검결(위력) · 경신공(이속) · 호신강기(기혈·방어) · 영근(쿨다운) ·
천리안(획득 범위) · 금단(범위·회복).

슬롯은 법보 6칸 + 공법 6칸입니다.

## 적과 보스

마기 잔영 · 요랑 · 석귀 · 부적귀 · 혈갈(죽으면 둘로 분열) · 마수사(엘리트).

- **8:00** — 요왕 창랑(妖王 蒼狼). 지면에 돌진 경로를 그린 뒤 돌진, 요랑 무리를 소환.
- **15:00** — 마존 흑천(魔尊 黑天). 체력 구간마다 3페이즈: 검비 → 흑구환 → 소환.
  격파하면 **승천(昇天)**, 기혈이 다하면 **좌화(坐化)**.

## 구조

```
src/
  core/     Game(상태 머신·루프)  Time  Input  SpatialHash  Pool  RNG  Events
  world/    Scene  Camera  Terrain  Sky
  art/      faces  ChibiBuilder  enemyGeometry  materials  textures  geometry  vfx
  entities/ Player  EnemyManager  ProjectileManager  PickupManager  BossManager
  combat/   WeaponSystem  Stats  damage  upgrades  weapons/(법보 12종)
  data/     characters  weapons  passives  enemies  waves  realms  validate
  ui/       Hud  LevelUpModal  TitleScreen  ResultScreen  OverlayCanvas  icons  DebugOverlay
```

설계상 중요한 점 몇 가지:

- **고정 타임스텝(60Hz) + 렌더 보간.** 시뮬레이션은 절대 가변 dt를 보지 않으므로
  60Hz와 144Hz에서 밸런스가 동일합니다.
- **인스턴싱.** 적·투사체·영기·VFX는 종류별로 `InstancedMesh` 하나씩. 적 900마리가
  드로우콜 45개, 시뮬레이션 틱당 0.18ms입니다.
- **고정 용량 풀 + 병렬 타입드 배열.** 엔티티마다 객체를 만들지 않고, 런 도중에는
  아무것도 할당하지 않습니다.
- **공간 해시(uniform grid).** 충돌과 적끼리 밀어내기를 O(n)으로 처리합니다.
  이 밀어내기가 없으면 적들이 한 덩어리로 겹쳐버립니다.
- **외부 에셋 0.** 모델·텍스처·폰트·이미지 파일이 하나도 없습니다. 얼굴은
  Canvas2D로 그려 머리 곡면에 입히고, 지형·법보·적은 전부 프리미티브를 병합해
  만듭니다.
- **사운드 없음.** 설계 단계에서 명시적으로 제외했습니다.

## 밸런스 수정

수치는 전부 `src/data/` 안에만 있습니다. 로직 파일에는 게임 수치가 없습니다.

- `characters.js` — 기본 스탯, 캐릭터 특성
- `weapons.js` — 법보 12종의 레벨별 피해·쿨다운·개수·범위
- `passives.js` — 공법 6종의 레벨당 효과
- `enemies.js` — 적 스탯과 시간에 따른 스케일링 공식
- `waves.js` — 15분 스폰 타임라인(30초 단위)
- `realms.js` — 경지 구간과 레벨업 요구 영기

부팅할 때 `validate.js`가 이 테이블들을 검사합니다. 진화가 존재하지 않는 id를
가리키거나, 웨이브에 구멍이 있거나, 법보 레벨 수가 안 맞으면 **즉시 정확한 메시지와
함께 실패**합니다. 런 도중에 undefined로 터지는 것보다 낫습니다.
