### 규정과 권장의 구분

- `브라우저에서 즉시 실행되는 웹 빌드`와 심사 기간 접근 가능한 플레이 링크는 필수다.
- `HTTPS`는 안전한 공개 배포를 위한 준비 기준으로 사용하지만, 공식 화면의 필드 안내는 `https://` 입력 예시이고 약관이 HTTPS 자체를 독립 필수 조건으로 명시하지는 않는다.
- 썸네일 `16:9`, `JPG/PNG`, `10MB 이하`는 2026-08-10 공식 신청 화면에서 모두 권장으로 표시된다. 실제 서버 허용 형식·한도는 제출 직전 다시 확인한다.
- 3분 이내 실제 플레이 영상과 Codex 과정 설명은 선택 제출·가산점이지, Track 1의 필수 제출 필드는 아니다. 다만 경쟁력과 심사 설명을 위해 권장한다.
- Codex 사용 자체는 필수지만, 공식 페이지는 프롬프트 원문·세션 로그·스크린샷 형식을 지정하지 않는다. 아래 증빙은 준수와 재현성을 위한 내부 권장 형식이다.

## 증거·로그 요구사항

### 브라우저 플레이 링크 증거

```text
run_id: <미입력>
build_id: <미입력>
commit_or_deploy_hash: <미입력>
deployment_url: <미입력>
tested_at_kst: <미입력>
browser: <미입력>
viewport: <미입력>
session_type: <새 프로필/시크릿/로그아웃>
result: <시작·핵심 플레이·결과·재도전>
evidence: <실플레이 영상·스크린샷·콘솔/네트워크 로그 경로>
```

필수 확인:

- [ ] URL은 외부 심사자가 접근할 수 있다.
- [ ] 설치·로그인·승인·유료 결제가 없다.
- [ ] 첫 화면에 조작법과 목표가 보인다.
- [ ] 핵심 기능이 새 브라우저 세션에서 재현된다.
- [ ] 영상·스크린샷·로그·배포 빌드가 동일 `run_id`·`build_id`다.
- [ ] 자동 테스트나 headless PASS를 실제 사용자 가시 성공으로 보고하지 않는다.

thumbnail_path: output/releases/yeongheo-geomga-thumbnail-v5.2-1920x1080.png
mime_type: image/png
width: 1920
height: 1080
file_size_bytes: 2341071
sha256: cae7d30361db3db5a3a4086a500b88d70355d3f88631fe13deb6c0e4404d4545
