# 제출 자산 권리 최종 확인서

> 목적: 마스터가 제출 직전에 75개 runtime 이미지 자산의 권리 게이트를 한 번에 확인하기 위한 문서입니다. 실제 동의값은 비워 두며, 이 문서는 신청서·제출 버튼을 대신하지 않습니다.
>
> 기준 시각: 2026-08-12 KST
> 현재 판정: **권리 증거 0/75 · 제출 차단**
> 상세 원장: [`ASSET_RIGHTS_LEDGER.md`](./ASSET_RIGHTS_LEDGER.md)

## 먼저 확인할 현재 상태

- 제출 allowlist는 75개입니다. 직접 출력 8개, sprite source chain 16개, release-v3 UI source chain 19개, v5 의미 아이콘 source chain 32개가 기술적으로 추적되어 technical provenance chain은 75/75입니다. 이 수치는 법적 권리 확인이 아닙니다.
- 스프라이트 중 13개는 source sheet와 local ImageGen original의 SHA가 직접 일치합니다. 기존 원본 미검출이던 `AS-04`, `AS-14`, `AS-16`은 정확한 `.codex/generated_images` 원본, archived generation event/revised prompt, 변환 명령을 복구했고, 격리 재현한 source와 runtime이 현재 파일과 byte·RGBA pixel 모두 exact match했습니다.
- 위 3개 원본과 재현 증거는 비배포 `artifacts/2d-build/provenance/recovered-imagegen-originals/`에 보존하고 `tools/yeongheo/recovered-provenance-manifest.json`으로 해시를 고정했습니다. 따라서 `exact original 미검출`은 0/75이지만, 생성 계정·Input 권리·팀 권한·제3자 권리·대회 공개 허락은 여전히 0/75 미확인입니다.
- SHA-256, 파일 크기, mtime, `sourceUrl`, 매니페스트, 생성 로그와 결정적 재현이 있어도 법적 권리를 대신하지 않습니다.

## 공식 약관의 경계

- [OpenAI Terms of Use (Rest of World)](https://openai.com/policies/row-terms-of-use/)는 2026-01-01 시행본입니다. `Output` 조항은 법이 허용하는 범위에서 사용자와 OpenAI 사이의 Output 소유 및 OpenAI가 가질 수 있는 권리의 양도를 규정하지만, 사용자가 Input에 필요한 권리·라이선스·허락을 보유할 책임도 둡니다. Output의 비고유성, 제3자 Output의 별도 조건, 사람의 검토 의무와 비침해 보증 부재도 함께 확인해야 합니다.
- [OpenAI Service Terms](https://openai.com/policies/service-terms/)는 시각 기능으로 사람을 식별하거나 민감정보를 추론하거나, 명시적 동의와 필요한 권리 없이 사람의 likeness를 재현하는 사용을 제한합니다. 이 약관은 특정 로컬 파일의 생성 계정, 원천 Input, 팀 소유권을 증명하지 않습니다.
- [OpenAI Game Builders Seoul 참가 약관](https://openaigame2026.com/ko/terms)은 대회 제출물의 AI 생성물·외부 에셋을 포함한 권리 확보, 제3자 권리 비침해, 제출·공개 권한을 별도 요구합니다. OpenAI 약관의 일반 Output 조항만으로 대회 약관 게이트를 통과한 것으로 보지 않습니다.

## 6개 예/아니오 확인문

아래 `확인값`은 비워 두었습니다. 각 문장은 **예**일 때만 해당 게이트를 통과하며, `아니오` 또는 공란이면 관련 자산과 썸네일·영상·공개 build를 계속 차단합니다. 확인에는 이름, 이메일, 계정 ID, 연락처, 토큰을 적지 않습니다.
