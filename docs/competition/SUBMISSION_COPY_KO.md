## 2. 사실 경계와 현재 상태

### 현재 확인된 기반

- 기본 진입점은 PixiJS 기반 2D 런타임이다. 기본 경로는 src/main.js에서 src/runtime2d/로 이어진다.
- 개발용 레거시 Three.js 경로는 출품 빌드의 제품 약속이 아니다.
- 현재 live CombatWorld2D는 ContestPacing2D의 420초 하드 타임아웃을 사용한다. 900초 waves.js 테이블은 레거시·확장 데이터로 남아 있다.
- ContestPacing2D의 코드 기준 이벤트는 20초 첫 맹세, 120초 POI 강조, 180초 중간 보스, 330초 최종 보스, 420초 좌화 타임아웃이다.
- DaoVows2D는 검맥·설맥·심맥의 기본·심화·완성을 모델링하고 Game2D에서 전투 보정을 적용한다. 현재 선택 창은 20초·165초·270초다.
- BossPatterns2D는 옥허진장이 선택한 맹세를 읽어 3개 체력 페이즈별 전조·패턴을 CombatWorld2D에서 실행한다.
- FormationDirector2D는 75초·140초·215초·290초·365초 진을 생성하고, WorldInteractions2D는 seed 기반 POI·E 상호작용·보상을 연결한다.
- 현재 검증 결과는 npm test 64개 파일·704개 테스트 통과, npm run build 통과(Vite 8.1.5, 765 modules transformed), npm run assets:audit 116/116, runtime build audit 72/72 통과다.
- 최종 로컬 실행 청크 `Game2D-BxmAcfZT.js`(SHA-256 `0c2d1293f30cc94122d22b0e5650e6d808087a20ecc62dbc3a08b946c4682ddf`)를 담은 새 Web ZIP에서 180초 중간보스, 330초 옥허진장, 정확히 420초 심맥 승천(레벨 33·2,457처치·보스 2·도가 3/3), 결과→재도전과 일시정지를 통과했고 콘솔 error/warning은 0건이었다. 피해 무효화·시간 점프·보스 강제 소환 없이 실제 WASD·축지법·카드 클릭으로 완주했으므로 일반 showcase 밸런스 증거로 사용한다.
- 이 문서는 코드 연결 상태와 제출 전 사용자 게이트를 분리한다. 구조·로직 PASS는 Windows Chromium 실플레이·시각 승인·공개 배포 PASS를 대신하지 않는다.
